🎓 Study Nest – Learning Management System

Study Nest is a full-stack Learning Management System (LMS) built using the MERN Stack. The platform provides students with an organized and interactive learning environment where they can browse courses, enroll in free or paid programs, watch video lectures, track progress, and rate courses.

The system includes a comprehensive admin dashboard for managing courses, lectures, chapters, enrollments, and platform analytics. Secure authentication is handled through Clerk, while Stripe powers online course payments. The platform also includes a WhatsApp-based communication system for user support.

🚀 User Features
1. Browse available courses
2. Watch demo lectures before enrollment
3. Enroll in free and paid courses
4. Access structured video lectures
5. Track course progress
6. Rate and review courses
7. View enrolled courses in "My Courses"
8. Secure login and signup using Clerk
9. Contact support through WhatsApp integration

🛠️ Admin Features
1. Add and manage courses
2. Create lectures and chapters
3. View and manage bookings
4. Monitor revenue and enrollments
5. Analyze platform performance
6. Delete and update course content

🔧 Tech Stack
1. React.js
2. Node.js
3. Express.js
4. MongoDB
5. Clerk Authentication
6. Stripe API
7. WhatsApp Integration

🎯 Project Objective
To provide a scalable, secure, and user-friendly online learning platform that simplifies course management, content delivery, enrollment handling, and progress tracking for both learners and administrators.
